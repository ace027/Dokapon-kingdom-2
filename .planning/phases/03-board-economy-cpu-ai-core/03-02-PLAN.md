```ts
export const EFFECT_TAGS = ["gold","loseGold","loseGoldBp","goldBpAll","item","battleBuff","townValueBp","taxHoliday","shopsClosed","warpAll","warpTo","swapPositions","spinMod","healBp","damageBp","xp","masteryWin","transferBp"] as const;
export type EffectTag = (typeof EFFECT_TAGS)[number];
export type EffectTarget = "self"|"all"|"leader"|"lowest"|"random-player"|"random-rival";
export type TownTarget = "random-owned-town"|"all-owned-towns";
export type Effect =
  | { tag: "gold"; target: EffectTarget; amount: number }
  | { tag: "loseGold"; target: EffectTarget; amount: number }
  | { tag: "loseGoldBp"; target: EffectTarget; bp: number }
  | { tag: "goldBpAll"; bp: number }
  | { tag: "item"; target: EffectTarget; table: string }
  | { tag: "battleBuff"; target: EffectTarget; stat: "atk"|"def"; bp: number; battles: number }
  | { tag: "townValueBp"; target: TownTarget; bp: number }
  | { tag: "taxHoliday" }
  | { tag: "shopsClosed"; amount: number }
  | { tag: "warpAll"; node: "castle" }
  | { tag: "warpTo"; target: EffectTarget; node: "castle"|"random-empty"|"nearest-temple" }
  | { tag: "swapPositions"; target: "self"; with: "random-rival" }
  | { tag: "spinMod"; target: EffectTarget; value: number; uses: number }
  | { tag: "healBp"; target: EffectTarget; bp: number }
  | { tag: "damageBp"; target: EffectTarget; bp: number }
  | { tag: "xp"; target: EffectTarget; amount: number }
  | { tag: "masteryWin"; target: EffectTarget; amount?: number }
  | { tag: "transferBp"; from: EffectTarget; to: EffectTarget; bp: number };
export interface EffectBuff { kind: "spinMod"|"atkBp"|"defBp"|"coinLock"; value: number; uses: number }
export interface EffectWorld { /* all readonly, JSON-plain, records keyed by player/town id */
  players: readonly string[];                       // seat order
  gold: Readonly<Record<string, number>>;
  hp: Readonly<Record<string, number>>;
  maxHp: Readonly<Record<string, number>>;
  positions: Readonly<Record<string, string>>;
  assets: Readonly<Record<string, number>>;         // precomputed by the caller (leader/lowest)
  towns: Readonly<Record<string, { owner: string | null; value: number; base: number }>>;
  buffs: Readonly<Record<string, readonly EffectBuff[]>>;
  bags: Readonly<Record<string, readonly string[]>>;
  bagCap: Readonly<Record<string, number>>;
  xpGain: Readonly<Record<string, number>>;
  masteryGain: Readonly<Record<string, number>>;
  taxHoliday: boolean;
  shopsClosedUntil: number;
  clock: number;                                    // (week - 1) * 6 + round
}
export interface EffectTables {
  itemTables: Readonly<Record<string, readonly { id: string; weight: number }[]>>;
  sellValue(itemId: string): number;                // gold for an overflow item
  castle: string; emptyNodes: readonly string[];
  nearestTemple(from: string): string | null;
}
export interface EffectRng { int(min: number, max: number): number }
export interface EffectResult { tag: string; playerId: string | null; townId: string | null; amount: number; node: string | null }
export function applyEffects(effects: readonly Effect[], world: EffectWorld, tables: EffectTables, rng: EffectRng, actor: string | null): { world: EffectWorld; results: EffectResult[] };
export function resolveTarget(target: EffectTarget, world: EffectWorld, rng: EffectRng, actor: string | null): string[];
```
Semantics (binding):
- `applyEffects` folds `effects` in order over an immutable `world` (returns a new object; never mutates input records or arrays; build records with `Object.fromEntries`, read with `Object.hasOwn`/`ownGet`). Results are in effect order, then target seat order. Exhaustive `switch` on `tag` with a `never` default so a new tag fails typecheck.
- `resolveTarget`: `self` is `[actor]` (empty when `actor === null`); `all` is every player in seat order; `leader` is the player with maximum `assets` (ties: maximum `gold`, then lowest seat); `lowest` is minimum `assets` (ties: lowest seat); `random-player` is `[players[rng.int(0, n-1)]]`; `random-rival` draws from players other than the actor in seat order (`rng.int(0, k-1)`), empty when none. Empty targets yield one zero result per effect (`{tag, playerId: null, townId: null, amount: 0, node: null}`), never a throw.
- `gold`: gold += amount (cap at `MAX_COUNTER` 2147483647); result amount = applied. `loseGold`: lose `min(amount, gold)`; result amount = lost. `loseGoldBp`: lose `floor(gold * bp / 10000)`. `goldBpAll`: per player seat order, `delta = floor(gold * |bp| / 10000)` applied with the sign of `bp`; result per player with the signed applied delta.
- `item`: one `rng.int(1, totalWeight)` per target in seat order against `tables.itemTables[table]` (cumulative in table order; unknown table or total weight 0: zero result). If `bags[p].length < bagCap[p]` append the id and return `{tag: "item", amount: 1}` (no id in the result); otherwise gold += `tables.sellValue(id)` and return `{tag: "item-sold", amount: gold gained}`.
- `battleBuff`: push `{kind: stat === "atk" ? "atkBp" : "defBp", value: bp, uses: battles}`; `spinMod`: push `{kind: "spinMod", value, uses}`. Max 4 buffs per player: pushing a fifth drops the oldest first. Result amount = value or bp.
- `townValueBp`: owned towns ordered by town id ascending; `random-owned-town` draws `rng.int(0, k-1)`, `all-owned-towns` applies to each; `value = clamp(value + floor(value * bp / 10000), floor(base / 2), 3 * base)` (negative `bp` uses `value - floor(value * |bp| / 10000)`); result `townId`, `playerId` = owner, amount = signed change; no owned town: one zero result.
- `taxHoliday`: `taxHoliday = true` (result amount 1). `shopsClosed`: `shopsClosedUntil = max(current, clock + amount)`.
- `warpAll`: every player to `tables.castle` (one result per player, `node` = destination). `warpTo`: `castle`; `random-empty` draws `rng.int(0, emptyNodes.length - 1)` (empty list falls back to the castle); `nearest-temple` uses `tables.nearestTemple(position)` (null falls back to the castle). `swapPositions`: actor with the `random-rival` draw; swaps positions; two results; no rival: zero result.
- `healBp`: skipped (zero result) when `hp === 0`; else `hp = min(maxHp, hp + floor(maxHp * bp / 10000))`; result = applied heal. `damageBp`: skipped when `hp === 0`; else `hp = max(1, hp - floor(maxHp * bp / 10000))`; result = applied damage.
- `xp`: `xpGain[p] += amount`; `masteryWin`: `masteryGain[p] += amount ?? 1`. `transferBp`: `from` and `to` each resolve to one player (first element); same player or empty gives a zero result; moves `floor(gold(from) * bp / 10000)`.
- Randomness order: targets resolve (draws for `random-*`) in effect-list order before the effect's own draws (item weight draw, town draw, empty-node draw); one draw per decision, never for a decision that has a single candidate (a one-element draw list consumes no rng).

Tests (`effects.test.ts`, call `usePurityTraps()` like the other core tests): one test per tag asserting the exact new world fields and `results` (all 18); one test per documented branch (bag full -> `item-sold`; no owned town; no rival; KO'd target for `healBp`/`damageBp`; `damageBp` floor at 1; heal cap at max; buff overflow drops the oldest; `townValueBp` clamps at both bounds and its negative branch; `goldBpAll` negative; `loseGold` capped by gold; `transferBp` same player; `leader`/`lowest` tie-breaks; empty `emptyNodes`/null temple fallbacks); determinism (same seed -> identical results twice, and a recorded sequence of rng draws asserted via a recording rng for one multi-random effect list to pin the draw order); no mutation (inputs deep-frozen with a local `deepFreeze` helper); prototype-id pool (players named `toString`, `valueOf`, `hasOwnProperty` in every record and `towns` keyed likewise); results never contain item ids (assert no result string field equals a bag item id). Each negative/branch test is a single mutation of a valid fixture (PIT-001).

Edge/error cases: empty `players`; one-player world; `amount` at `MAX_COUNTER` saturating gold; table with zero total weight; `nearestTemple` returning the current position.

Create `packages/core/src/board/decks.ts` (pure; imports nothing from `handlers/` or `types.ts`). Export:
```ts
export interface DeckShape { draw: readonly string[]; discard: readonly string[] }
export interface DeckRng { int(min: number, max: number): number }
export function shuffle<T>(items: readonly T[], rng: DeckRng): T[];
export function drawCard(deck: DeckShape, pool: readonly string[], eligible: (id: string) => boolean, rng: DeckRng): { deck: { draw: string[]; discard: string[] }; id: string | null };
export function drawFromList(remaining: readonly string[], pool: readonly string[], rng: DeckRng): { remaining: string[]; id: string | null };
```
- `shuffle`: copy, then Fisher-Yates for `i = n - 1` down to `1`: `j = rng.int(0, i)`, swap `a[i]`, `a[j]` (a list of length <= 1 consumes no rng).
- `drawCard`: (1) if `draw` and `discard` are both empty (uninitialised deck) set `draw = shuffle(pool)`. (2) Find the first index in `draw` whose id satisfies `eligible`; if found, remove that single card keeping the other cards in their order, push it on `discard`, return it. (3) If none: new `draw = [...draw, ...shuffle(discard)]`, `discard = []`, search again; found -> as in (2). (4) Still none: return `{deck: {draw: <merged>, discard: []}, id: null}` (no draw this time; ineligible cards stay in order). `pool` empty and deck empty returns `id: null`.
- `drawFromList` (decree deck): if `remaining` is empty set it to `shuffle(pool)`; return the first element and the rest; empty pool gives `id: null`.
- Never mutate inputs; all ids are plain strings; no record reads (arrays only), so PIT-002 is satisfied structurally (test it with ids `toString`, `valueOf`, `__proto__` in the pool).

Tests (`decks.test.ts`): `shuffle` golden for `["a","b","c","d","e","f","g","h"]` with a rng wrapper around `seedRng("shuffle-golden")` and `nextInt` (the wrapper advances an `RngState` held in a closure); pin the resulting order **and** cross-check it against a test-local independent Fisher-Yates that calls `nextInt` directly (two derivations must agree); record with `// pinned from TS engine (PRF-004), cross-checked`. Further tests (each single-mutation from a valid fixture): uninitialised deck builds from the pool (draw length pool-1, discard length 1); skip-ineligible keeps the draw order (wild cards ahead of the first eligible stay put); reshuffle path when no eligible card is in `draw` (discard re-enters behind the kept ineligible cards, shuffle consumed exactly `len(discard) - 1` draws); `id: null` when nothing is eligible even after the reshuffle (deck returned merged, no discard); empty pool; `drawFromList` refill when exhausted and no repeat until exhausted over `pool.length` consecutive draws (all distinct, then the next draw is the first of a fresh shuffle); no mutation of inputs (deep-frozen); rng draw counts asserted with a counting rng.

Edge/error cases: duplicate ids in `pool` (documented behaviour: drawn as given, deserialize in 03-01b/03-04 prevents duplicates); `eligible` throwing is not caught (a bug).
