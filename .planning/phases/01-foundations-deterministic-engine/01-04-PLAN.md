Required interfaces/content structure:
- `views.ts`: `Viewer`, `PlayerView`, `viewFor`, `redactEvent`, `eventsFor` exactly per the spec.
  - `viewFor` builds a **new** object `{ v, viewer, public: state.public, self }`. It never spreads `state`.
  - `self` is `Object.hasOwn(state.private, viewer) && state.public.players.includes(viewer) ? state.private[viewer] : null`.
- `replay-file.ts`:
  - `export class ReplayFileError extends Error {}`.
  - `export function replayFile(filePath: string): { line: string; result: ReplayResult }`.
  - Reads the file with `readFileSync` (read errors become `ReplayFileError("cannot read <path>")`), then `JSON.parse` (errors become `ReplayFileError("invalid JSON")`).
  - Requires a plain object with `settings` and an `actions` array (else `ReplayFileError("expected {settings, actions[]}")`).
  - Calls `replay(settings as GameSettings, actions)`; a `SettingsError` becomes `ReplayFileError("invalid settings: <msg>")`.
  - Returns `line = \`hash=${hashState(state)} turn=${state.public.turn} counter=${state.public.counter} events=${events.length} rejections=${rejections.length}\``.
- `cli.ts`:
  - `const [cmd, file, ...rest] = process.argv.slice(2)`.
  - If `cmd !== "replay"`, or `file` is missing, or `rest.length > 0`: print `usage: sim replay <file.json>` to stderr and exit 2.
  - Otherwise `replayFile(path.resolve(process.cwd(), file))` and print the line; a `ReplayFileError` prints `error: <message>` to stderr and exits 2.
- `render.ts`: `renderView(view: PlayerView, events: readonly GameEvent[]): string` returns lines:
  1. `Usurpia — viewer: <viewer>`
  2. `turn <n> · active <player> · phase <phase>`
  3. `counter <n>`
  4. `last roll: <player> rolled <value>` or `last roll: —`
  5. `your note: <note>`, only when `self` is non-null (`(none)` if the note is null)
  6. `events:`
  7. one `- <type>` line per event

  Lines are joined with `\n`.
- `main.ts`:
  1. `const created = createGame({ v: 1, seed: "demo", players: ["p1", "p2"] })`.
  2. Apply `{v:1,type:"sample/roll",playerId:"p1"}` then `{v:1,type:"sample/setSecret",playerId:"p1",note:"p1 secret"}` via `reduce`, accumulating events. If any result is `ok:false`, throw.
  3. Render `renderView(viewFor(state, "p2"), eventsFor(events, "p2"))` into `#app` with a null check.
Edge/error cases:
- `viewFor` for `"spectator"` and for an unknown id `"ghost"`: `self === null`.
- `redactEvent` for a `players` visibility with an empty ids array: `null` for everyone.
- `eventsFor` preserves order and does not mutate the input.
- A fixture file missing `actions`, invalid JSON, or an unreadable path each produce the right `ReplayFileError`.
